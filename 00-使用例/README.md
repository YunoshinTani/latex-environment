# 使用例

各フォルダが一つの独立した文書です。
親フォルダをVS Codeで開き、試したい例のTeXファイルを開いてビルドしてください。

| フォルダ | 最初に開くファイル | ビルドの短い名前 |
| --- | --- | --- |
| 01-学校形式-upLaTeX | 実験報告書.tex | school |
| 02-学校形式-pLaTeX | 実験報告書.tex | school-platex |
| 03-数式とグラフ | main.tex | report |
| 04-欧文 | main.tex | english |
| 05-biblatexとBiber | main.tex | bibliography |

新しいレポートには、近い例のフォルダをコピーして親直下の「01-実験名」などへ配置します。
本文と同じ場所の .latexmkrc も一緒にコピーしてください。生成済みの export は不要です。
実験ごとに、独自のTeXファイル名・画像・文献・出力先を持てます。

学校形式の表紙スタイルは公開用のオリジナルです。学校指定の正式な表紙ではありません。
実際の課題に指定がある場合は、配布されたスタイルを手元の実験フォルダで使用してください。
