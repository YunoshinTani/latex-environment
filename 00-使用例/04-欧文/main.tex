\section{One project, one build configuration}
This independent example uses pdfLaTeX by default. Set the engine to
\texttt{xelatex} in the local \texttt{.latexmkrc} to build it with XeLaTeX.
There are no operating-system font names or personal paths in this document.
Latexmk resolves references and runs BibTeX when required\cite{latexmk}.

\section{Mathematics and cross-references}
\label{sec:math}
For a resistor with resistance \(R\), the current is
\begin{equation}
  I=\frac{V}{R}.
  \label{eq:current}
\end{equation}
Equation~\eqref{eq:current} and Table~\ref{tab:measurements} are linked to their
definitions. No reference numbers are entered manually.

\section{Building from another folder}
The helper scripts locate this project relative to their own location.
The editor recipe resolves paths relative to the root TeX file.
Consequently, moving the repository does not require editing absolute paths.
