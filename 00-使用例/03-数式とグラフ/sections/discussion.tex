\section{考察とビルドの確認}
\ref{sec:results}節の表とグラフは，電圧と電流が比例することを示す。
数式・表・図の番号は手入力せず，\verb|\label| と \verb|\ref| で参照する。
文書を編集した後も，latexmk によって参照が更新される。

\subsection{このPDFで確認できること}
\begin{enumerate}
  \item 日本語と数式が正しく表示されること。
  \item 表とグラフが生成され，相互参照に未解決の記号が残らないこと。
  \item この文書の最後に参考文献が表示されること。
  \item 本文を分割したファイルからルート文書をビルドできること。
\end{enumerate}

\subsection{文書を自分のレポートに変える}
\texttt{main.tex} の題名・著者・日付と，
\texttt{sections/} 内の本文を変更する。
図や文献を追加した場合も，同じビルド操作を使える。
このサンプルには独自の学校用スタイルファイルを含めていないため，
標準的な TeX Live のパッケージで再生成できる。

\subsection{別の文献処理方式を試す}
従来の BibTeX を使うこの文書に加え，
同じ使用例フォルダ内に biblatex と Biber の独立した文献管理の例を用意している。
各例には専用の \texttt{.latexmkrc} があり，異なる文書のエンジン指定を分離できる。
